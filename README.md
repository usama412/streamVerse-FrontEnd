# StreamVerse

Premium streaming platform frontend built with React + Vite + TypeScript + Tailwind CSS.

## Run

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

## Included
- Cinematic responsive UI
- Movies, TV, Anime, Live, Search
- Video player with public demo video sources
- My List + Watch History persisted in localStorage
- Profiles, authentication screens, pricing and checkout UI
- Blog platform
- Help/contact/settings
- Admin dashboard + analytics charts
- REST API service layer ready for a backend
- 50+ movies, 20+ shows, 30+ anime, 30+ blog entries, people and live events

The image URLs are Unsplash sources used as demo/open web imagery; replace them with licensed assets for a commercial launch.
